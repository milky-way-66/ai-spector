# Work 04 — Enable Agent Skills

**Course:** [Index](README.md) · [Overview](00-overview.md) · [Previous](03-finish-setup-in-chat.md)

**Goal:** Turn on skill routing so the agent knows which tool to run for each type of request (analyze, generate SRS, graph query, etc.).

**Before you start:** Work 02 (Initialize a Project).

**Custom templates later?** Also enable `ai-spector-template-import` when you import your own pack ([Work 17](17-custom-template-packs.md)).

---

## What Are Skills?

Skills are instruction files the agent reads to know *how* to handle specific phrases. Without skills enabled, the agent will respond generically and won't automatically call AI Spector tools.

---

## For Cursor

### 1. Open Settings

`Cmd+Shift+P` (Mac) or `Ctrl+Shift+P` (Windows/Linux) → search **"Cursor Settings"** → open it.

### 2. Go to Rules → Agent Skills

Look for the **Rules** section in the left sidebar. Find **Agent Skills**.

### 3. Enable all skill folders

You will see a list of folders under `.cursor/skills/`. Toggle **every folder on**. The skills you need are:

- `ai-spector` — core documentation workflow
- Any other folders that were generated by init

### 4. Reload MCP

Still in Cursor Settings, find **MCP** and click **Reload** (or restart Cursor). This activates the `ai-spector` MCP server defined in `.cursor/mcp.json`.

---

## For Claude Code

Skills load automatically from `.claude/skills/` when Claude Code starts. You don't need to enable them manually.

### Reload MCP

The MCP server is registered in `.mcp.json` at your project root. To reload it:

1. Exit Claude Code (`/exit` or `Ctrl+C`)
2. Restart: `claude` in the project root

Or, if Claude Code is running in a session, type `/mcp` to see MCP status.

---

## Check

### In Cursor

In the chat panel, type:

```
analyze my data source
```

The agent should respond with a plan to run the `ai-spector` MCP tool, not a generic "I don't have a tool for that" message.

### In Claude Code

Type:

```
validate the graph
```

The agent should invoke the graph validation tool or explain that the graph is empty (that's fine — the graph is empty at this stage).

## Troubleshooting

**Cursor: skills folder is not visible**

The `.cursor/skills/` folder might not have been created. Check it exists:

```bash
ls .cursor/skills/
```

If it's empty or missing, re-run:

```bash
npx ai-spector@latest init --registry http://10.101.0.239:4873
```

Choose Cursor when prompted.

**Agent still responds generically**

After enabling skills in Cursor, fully restart Cursor (not just the window — quit and reopen). Skills are loaded at startup.

**MCP tools not available**

Check `.cursor/mcp.json` (Cursor) or `.mcp.json` (Claude Code) exists and contains an `ai-spector` server entry. If missing, re-run init.
