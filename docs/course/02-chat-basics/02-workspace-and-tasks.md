## Tasks & resume

Generation runs are **tasks** with saved state (clarifications, plans, wave progress).

```
active tasks
```

```
resume my SRS
```

```
pause task
```

| Phrase | Means |
|--------|-------|
| *resume SRS* | Continue a **generation task** |
| *review documents* | **Document sign-off** (different workflow) |
