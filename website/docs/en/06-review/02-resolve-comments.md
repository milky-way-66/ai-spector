# Resolve comments

**Section:** [Review](README.md) · **Course:** [Home](../README.md)  
**Time:** ~10 min

**Goal:** Work through feedback comment threads on documents.

---

## In plain terms

Reviewers leave **comment threads** (e.g. C-001) on documents. When you have addressed the feedback, ask the agent to resolve comments. This is **not** formal document sign-off.

---

## You say → Agent does → You see

**You say:** *"resolve comments"*

**Agent does:** Shows open comment threads, plans fixes, edits documents, marks threads done.

**You see:**
- Inbox of open comments
- Proposed edits before commit
- Threads marked resolved when complete

---

:::exercise
**Paste in chat:**

```
resolve comments
```

**You should see:**
- List of open comment threads, **or**
- Agent says no open comments if inbox is empty
:::

:::roletip
**Tester** — use this after test review cycles; **BA** — after stakeholder feedback.
:::

## If something goes wrong

| Symptom | Say in chat |
|---------|-------------|
| Thread not closing | Ensure doc + comment metadata were updated together |
| Confused with doc approve | Comments = *"resolve C-012"*; sign-off = *"review documents"* |
