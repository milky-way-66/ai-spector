# Tasks and workspace

**Section:** [Everyday](README.md) · **Course:** [Home](../README.md)  
**Time:** ~10 min

**Goal:** Resume paused work, see active tasks, and check workspace health.

---

## In plain terms

Long workflows (SRS generation, reviews) can be **paused and resumed**. The agent saves progress. You can also ask for a **workspace check** when something feels misconfigured.

---

## Common phrases

| You want to… | Say (examples) |
|--------------|----------------|
| See paused work | *"active tasks"*, *"resume my SRS"* |
| Pause | *"pause task"* |
| Health check | *"check my workspace"* |
| Stale answers | *"open questions"* |

---

## You say → Agent does → You see

**You say:** *"active tasks"*

**Agent does:** Lists in-progress tasks with status.

**You see:** Task names, phases, and what to say to resume.

---

:::exercise
**Paste in chat:**

```
active tasks
```

**You should see:**
- Table or list of tasks (may be empty on a new project)
- How to resume if any task is paused

Then try:

```
check my workspace
```

**You should see:** Workspace findings table with pass/fail items.
:::

:::roletip
**Everyone** — use *"check my workspace"* when routing or setup seems broken.
:::
