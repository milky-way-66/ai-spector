# Translations *(tùy chọn)*

**Phần:** [Prototype](README.md) · **Bỏ qua nếu** chỉ cần 1 ngôn ngữ

**Mục tiêu:** Giữ bản dịch sync với doc chính.

---

Ngôn ngữ chính (`languages[0]`) được **generate**; ngôn ngữ khác được **dịch**.

```
add language vi
translation status
resolve translations
```
