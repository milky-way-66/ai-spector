# AI Spector — Project Adopt

Migrate **existing filled-in docs** from legacy layouts into canonical paths so
`workspace_check`, graph index, resolve-task, review, and generate workflows unlock.

**Related but different:** `ai-spector-template-import` installs **empty templates** for
future generation — not migration of existing SRS/BD content.
